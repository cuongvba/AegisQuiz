## 🧭 Hướng Dẫn Điều Hướng Nhanh Theo Vai Trò

### 1. Dành Cho Kỹ Sư Lập Trình (Software Engineers & Architects)
- Muốn hiểu tổng quan kiến trúc hệ thống và cách các service giao tiếp: xem **[Kiến Trúc Hệ Thống](architecture/SYSTEM_ARCHITECTURE.md)**.
- Muốn cắm thêm một Gameshow mới vào Đấu trường: xem **[Đấu Trường Gameshow Plugin Engine](modules/ARENA_PLUGIN_ENGINE.md)** và **[ARENA_PLUGIN_DEVELOPER_GUIDE.md](ARENA_PLUGIN_DEVELOPER_GUIDE.md)**.
- Muốn mở rộng định dạng nhận diện câu hỏi mới mà không cần sửa code: xem **[Động Cơ Bóc Tách Câu Hỏi Cấu Hình Động Vạn Năng](modules/UNIVERSAL_DYNAMIC_QUESTION_INGESTION_ENGINE.md)**.
- Muốn tích hợp API hoặc gọi WebSockets: xem **[Đặc Tả REST API](api/REST_API_REFERENCE.md)** và **[Giao Thức SignalR WebSockets](api/WEBSOCKET_SIGNALR_PROTOCOLS.md)**.
- Muốn tìm hiểu thuật toán bóc tách công thức toán từ file Word DOCX: xem **[DOCX & Math Engine](modules/DOCX_PARSER_AND_MATH_ENGINE.md)**.
- Muốn tìm hiểu mô hình phân hóa trình độ bằng Item Response Theory: xem **[IRT Adaptive Testing](modules/IRT_ADAPTIVE_TESTING.md)**.

### 2. Dành Cho Kỹ Sư Vận Hành & DevOps (DevOps & SysAdmins)
- Cài đặt, chạy Docker Compose, cấu hình Redis, PostgreSQL và Keycloak: xem **[Triển Khai & Vận Hành](devops/DEPLOYMENT_AND_OPERATIONS.md)**.
- Bảo mật phòng thi và quản lý chứng thư số: xem **[An Ninh & Chống Gian Lận](architecture/SECURITY_AND_PROCTORING.md)**.

### 3. Dành Cho Thầy Cô, Ban Tổ Chức & Người Dùng Cuối (Hosts & Learners)
- Tổ chức ngày hội đấu trường, các cuộc thi Olympia, Rung Chuông Vàng, Chiếc Nón Kỳ Diệu: xem **[Cẩm Nang Gameshow Đấu Trường](manuals/ARENA_GAMESHOW_MANUAL.md)**.
- Học sinh, sinh viên tìm hiểu cách làm bài, theo dõi năng lực và giải bài cùng AI: xem **[Cẩm Nang Người Học](manuals/LEARNER_USER_MANUAL.md)**.
- Học viên ôn thi sát hạch bằng lái xe máy & ô tô (A1, B1, B2, C, 60 câu điểm liệt & Sa hình): xem **[Cẩm Nang Người Học](manuals/LEARNER_USER_MANUAL.md)**, **[Chương Sát Hạch Lái Xe](AEGISQUIZ_UNIFIED_MASTER_SPECIFICATION.md#6-phân-hệ-khảo-thí--sát-hạch-lái-xe-quốc-gia-gplx-600-câu-60-điểm-liệt-tử-thần--sa-hình-ai)** & **[Đặc Tả Kỹ Thuật GPLX Module](modules/NATIONAL_DRIVING_LICENSE_MODULE.md)**.
- Cán bộ khảo thí, quản trị viên duyệt đề thi và ngân hàng câu hỏi: xem **[Cẩm Nang Quản Trị](manuals/ADMIN_AND_EXAM_MANAGEMENT_GUIDE.md)**.

## ⚡ Thông Tin Nhanh Về Stack Công Nghệ

| Thành Phần | Công Nghệ Sử Dụng | Phiên Bản | Ghi Chú |
| :--- | :--- | :--- | :--- |
| **Backend Core** | C# / .NET Web API | **10.0** | Clean Architecture, DI, Concurrency |
| **Realtime Engine** | ASP.NET Core SignalR | **10.0** | WebSockets transport, In-memory state |
| **Frontend Web** | React, TypeScript, TailwindCSS | **React 19, Vite 6** | Web Audio Synth, HTML5 Canvas 60fps |
| **Adaptive Microservice**| Python, FastAPI, NumPy, SciPy | **Python 3.11+** | Item Response Theory (3PL IRT Model) |
| **Primary Database** | PostgreSQL | **16+** | Entity Framework Core |
| **Cache & State** | In-Memory RAM + Redis | **7+** | Microsecond clock, Distributed lock |
| **Identity / Auth** | JWT + Keycloak OIDC + PKI | **24+** | Xác thực tập trung, bảo vệ dữ liệu thi |
